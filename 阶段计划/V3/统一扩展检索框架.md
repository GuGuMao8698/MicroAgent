# 统一扩展检索框架

## 目标
- 在 `MQE` 与 `HyDE` 之上补齐统一的“扩展-检索-合并”编排层。
- 负责管理多路扩展查询的并行检索、候选池分配、结果去重和分数组合。

## 为何排在当前顺序
- 统一框架依赖 `MQE` 和 `HyDE` 这两类原子能力先存在，否则编排层缺少稳定输入。
- 将它放在最后实现，能先验证单项增强的边际收益，再决定最终的组合方式和默认策略。

## 预期收益
- 把多个 query-side 增强收敛成一致的运行路径，避免每个策略各自维护一套检索和合并逻辑。
- 为后续和 `Jina Reranker v3`、`RAPTOR` 的组合提供稳定的候选输入层。

## 边界
- 统一框架属于 query-time 编排层，不替代基础检索、分块或摘要构建本身。
- 当前阶段只固定其职责、依赖关系和排序理由，不展开到候选池倍率、分数融合公式或开关策略细节。
