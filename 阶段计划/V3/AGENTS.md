# V3 子任务索引

`V3` 的主入口仍是上级 [V3.md](../V3.md)。这里仅按当前阶段顺序列出子任务，承接渐进式披露所需的详细说明。

## Contents
1. [Jina Reranker v3](Jina%20Reranker%20v3.md): 内部重排能力，放在现有 Infinity hybrid 初筛之后。
2. [智能分块](智能分块.md): 参考递归分块骨架，明确适合迁移和不直接照搬的部分。
3. [RAPTOR](RAPTOR.md): 层级摘要检索能力，服务长文档和多层级上下文组织。
4. [MQE](MQE.md): 最先落地的 query-side 检索增强，解决用词差异导致的召回不足。
5. [HyDE](HyDE.md): 第二阶段 query-side 检索增强，用假设答案段落缩小问题与文档的语义鸿沟。
6. [统一扩展检索框架](统一扩展检索框架.md): 在 MQE 与 HyDE 之后补齐扩展、检索、合并的统一编排层。

## Usage
- 需要判断 V3 当前任务顺序时，以这里的顺序为准，并与上级 [V3.md](../V3.md) 保持一致。
- 单个子任务的细节、约束和非目标以对应文档为准，不再回填到上级主入口。
