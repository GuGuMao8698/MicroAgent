# 智能分块

## 目标
- 为 `ragflow-lite` 提供更适合中文与 Markdown 文本的分块基线，作为 ingestion 阶段的可演进能力。
- 参考 `/home/xia/ragflow-lite/auto_tune_rag/src/core/chunk_optimizer.py` 中基于 `RecursiveCharacterTextSplitter` 的递归分块思路，但只吸收适合当前项目的部分。

## 适合迁移
- 保留递归分块方向，优先按段落、换行、标点和字符级回退切分文本。
- 保留 `chunk_size`、`chunk_overlap`、`separators` 作为可配置能力，后续可按文档类型扩展不同 profile。
- 保留 chunk 继续携带来源 metadata 的要求，至少能追踪原始文档来源和 chunk 顺序。
- 保留分块质量诊断入口，但将其定位为离线评估、日志指标或测试辅助，而不是主链路的硬门槛。

## 不直接照搬
- 不照搬 `auto_tune_rag` 中的中文启发式评分公式，因为它依赖该项目自己的文本分布和经验规则。
- 不照搬固定阈值、倍率和上限，例如 `0.5`、`0.7`、`1.1`、`1.2`、`1.5`、`800`、`150` 这类经验参数。
- 不照搬 `CHUNK_SIZE=256`、`CHUNK_OVERLAP=50` 这组默认值；`ragflow-lite` 需要按自己的 embedding、检索窗口和文档类型重新定标。
- 不照搬未提供实际行为收益的接口参数，以及默认热路径中的自动调参循环。

## 当前边界
- `智能分块` 属于 ingestion 侧能力，不负责 query-time 的扩展检索、重排和候选合并。
- 当前阶段先明确能力边界和迁移原则，后续再落具体参数、文档类型 profile 和离线评估方法。
