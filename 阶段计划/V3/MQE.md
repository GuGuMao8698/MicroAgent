# MQE

## 目标
- 通过多查询扩展提升召回率，缓解用户提问用词与文档表达不一致的问题。
- 将单一 query 扩展为多个语义等价或互补的查询，再合并检索结果。

## 为何排在当前顺序
- `MQE` 是最低风险、最容易回退的 query-side 增强，不需要改索引结构，也不改变默认检索主路径。
- 先做 `MQE`，可以用最小改动验证检索增强是否带来稳定收益，再决定是否叠加更重的生成式策略。

## 预期收益
- 改善因为同义表达、术语差异或用户表述过短导致的召回不足。
- 为后续 `HyDE` 和统一扩展检索框架提供第一种可复用的扩展 query 来源。

## 边界
- 当前阶段将 `MQE` 视为 query-time 增强，不改变 ingestion、chunking 或基础向量索引流程。
- 若性能或成本敏感，`MQE` 应保持可关闭和可回退，不成为新的硬依赖。
