## Active Boundaries
- 当前默认生产检索主路径仍是 Infinity hybrid。
- `Jina Reranker v3` 若落地，应作为内部重排而非新公共配置、新 API 形态或额外检索主路径。
- 文档上传默认走异步 ingestion pipeline。
- `POST /documents` 必须携带 `Idempotency-Key` header，接受上传后立即返回 `202` 和 `Location`，不等待索引完成。
- `GET /documents/{id}` 是默认轮询入口，用于观察 `queued` / `processing` / 终态。
- 默认装配使用进程内 background runner，并在处理异常时自动执行单次 retry。
- legacy 同步 `ingest()` 保留，但不再是默认路径。

## Usage
- 涉及当前阶段规划、范围判断或阶段性默认路线时，优先读取本文档。
- 需要查看某个 V3 子任务的目标、边界、排期理由时，优先从 `阶段计划/V3/README.md` 和对应子文档进入。
- 具体实现、测试、运行和分层约束仍以下级 `AGENTS.md`、代码和测试为准。
- `V4` 暂不在仓库根文档中暴露；待 `V3` 结束后，再切换根文档阶段声明。
